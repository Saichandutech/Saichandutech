## 📂 Featured Projects

### 1. 📉 Telecom Customer Churn Analysis
- **Tech:** Python, Pandas, NumPy, SQL, scikit-learn, Matplotlib, Jupyter
- **Description:** End-to-end analysis of why broadband customers leave. Cleans a messy extract with a full audit log
  (duplicates, inconsistent labels, nulls), segments churn in SQL with CTEs and window functions, and builds an
  explainable risk model (AUC 0.80). Finds a 243-customer high-risk segment churning at 57%, with a stakeholder-ready
  summary, recommendations, and a ranked retention call list of the 500 most at-risk active customers.
- 🔗 [View Project](https://github.com/Saichandutech/telecom-churn-analysis)

### 2. 🔍 Data Reconciliation & Validation Toolkit
- **Tech:** Python, Pandas, openpyxl, PyYAML, pytest
- **Description:** Config-driven tool that answers *"why don't the dashboard numbers match the source system?"*.
  Compares two extracts record by record (missing rows, duplicates, field-level mismatches with tolerance), checks
  control totals, and runs business-rule validation. Produces an audit-ready Excel workbook and HTML report that
  explain a $987 variance down to each record. Works on new datasets with only a config file (CRM vs billing
  example included) and is covered by 14 automated tests running in CI.
- 🔗 [View Project](https://github.com/Saichandutech/data-reconciliation-toolkit)

### 3. ⚙️ Automated Weekly KPI Reporting Pipeline
- **Tech:** Python, SQL, SQLite / PostgreSQL, openpyxl, Matplotlib, GitHub Actions
- **Description:** Replaces a manual weekly reporting routine with one scheduled command. Extracts data from three
  source systems, validates it with data-quality gates, loads a star-schema warehouse, calculates KPIs in SQL views,
  and delivers an Excel scorecard (with a data-quality audit tab), an email-ready HTML summary, and CSV extracts for
  Power BI. Automatic call-outs flag unusual KPI movements. Runs every Monday via GitHub Actions.
- 🔗 [View Project](https://github.com/Saichandutech/weekly-kpi-reporting-pipeline)

### 4. 🛒 Retail Sales Analytics in SQL
- **Tech:** PostgreSQL, SQL, PL/pgSQL, Python, Docker
- **Description:** Fourteen business questions answered entirely in PostgreSQL: month-over-month and year-over-year
  growth, top-N per region, Pareto analysis, RFM segmentation, cohort retention, and market-basket analysis. Includes
  a governed revenue view, a parameterised function, a stored procedure with a materialized view, data-quality checks,
  and BI-ready extracts for Power BI and Tableau. CI rebuilds the database in PostgreSQL 16 on every push and verifies
  every result.
- 🔗 [View Project](https://github.com/Saichandutech/retail-sales-sql-analytics)
